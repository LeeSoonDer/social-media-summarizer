# Project Overview

## Product
Social Summarizer is a Chrome Extension that helps users summarize social media content with AI.

## Core Problem
Users currently need to screenshot, record, copy, upload, and manually ask AI to summarize social posts or videos. The extension aims to reduce this to one click from the current social media page.

## Product Positioning
This is not a traditional crawler. It is an AI content understanding tool that turns social media content into compressed knowledge.

## MVP Platforms
- Xiaohongshu
- Instagram

## MVP User Flow
1. User opens a supported social media page.
2. User clicks the Chrome Extension icon.
3. Extension extracts page text and image data from the active tab.
4. Extension sends the extracted content to Gemini.
5. Popup displays bilingual structured summary.

## Target Output
- Chinese summary
- English summary
- Key points
- Mentioned tools/products
- Action suggestions
