# Debugging Prompt

When debugging this project:

1. Reproduce or identify the exact error message.
2. Locate the responsible file and function.
3. Explain the likely cause in beginner-friendly language.
4. Make the smallest safe fix.
5. Run available validation such as `node --check`.
6. Update `ai/current_state.md` and `ai/memory/known_issues.md` if the issue is important.
