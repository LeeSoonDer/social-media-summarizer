# README 用的三张截图

README 里已经留好位置，把文件按下面的名字放进 `docs/`，图就自动出来了。
文件名必须一致，否则 README 上会是三个破图标。

| 文件名 | 拍什么 | 要点 |
|---|---|---|
| `01-sidepanel.png` | 侧栏停在「本页」分区，右边是一条真实的社媒帖子 | 让人一眼看懂"左边是网页、右边是采到的内容"。顶部四个小标签（正文/画面字/图片/视频）要能看清 |
| `02-ocr.png` | 「画面」分区，已经扫过至少一屏，下方显示识别出的文字 | 最好选一条字都在图里的小红书帖，对比才强烈。底部那句「已并入第 N 屏（只扫了主图区域）」如果还在，一起拍进去 |
| `03-notes.png` | 「笔记」分区，有几条真实笔记，「本页相关」那一组有内容 | 展示"笔记绑定页面"这个核心设计。顶部输入框要在画面里 |

## 拍的时候

- **连浏览器窗口一起拍**，不要只截侧栏——读者需要看到"网页 + 侧栏"的关系。
- 宽度 1400–1600px 比较合适，GitHub 上显示清晰又不会太大。
- **先检查一遍有没有你的个人信息**：账号名、头像、私信、书签栏、标签页标题。
  这个仓库是公开的，截图会一直在那里。
- 挑内容本身没有争议的帖子。

## 放进去之后

不用改 README，文件名对上就行。commit 时记得 `git add docs/*.png`。
