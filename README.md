# Social Extractor

> 把你正在看的这一页——正文、图片上的字、视频的字幕——原样采下来，配一段中文说明，粘给任意网页版 AI。
> 全程在本机运行，不上传，不需要 API key。

**English TL;DR** — A Chrome side-panel extension that lifts the content of the social post you're
currently viewing (text, on-image text via local OCR, platform captions) into a clean prompt you paste
into any web AI. Runs entirely on-device: no server, no account, no API key, no cloud model calls.
Vanilla JS, Manifest V3, Tesseract.js bundled locally.

---

## 它解决什么问题

你想让 AI 帮你分析一条小红书笔记、一个短视频、一串推文。

但把链接直接丢给 AI，它多半打不开——就算打得开，也常常只看到标题就开始编。
小红书的内容大半画在图里，抖音的字幕烧在画面上，这些字根本不在网页代码里，
任何"读链接"的方案都拿不到。

这个扩展把这一步补上：**你在浏览器里看到什么，它就采下什么**，
整理成一段干净的原料，你复制、粘贴、提问。

给 AI 的稿子开头永远带着同一段说明，专治瞎编：

> 你没有看过这个视频或这些图片，不要假装看过，也不要凭标题推测内容。
> 原料里没有的信息，直接说没有，不要推测补全。

## 它做什么

- **采文字** —— 标题、正文、作者、话题标签，以及（可选的）已加载出来的评论。
- **读图上的字** —— 截下当前视口，用本机 OCR 把图上的字读出来。中文短视频的烧录字幕靠这个。
  多屏可累积合并去重，翻一张按一下 <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>。
- **取现成字幕** —— YouTube 这类提供字幕轨道的平台，直接拿整篇文本，又快又准。
- **攒材料** —— 采过的每一页自动进「集合」，最后一次性打包给 AI 做横向对比。
- **记笔记** —— 回车即存，自动绑定你当时在看的那一页；下次再打开同一页，笔记就在那儿。

## 它明确不做

- **不录音、不做语音转文字。** 这是权衡后砍掉的：本地语音模型要额外下载几百 MB，
  中文准确率还不稳，代价和收益不成比例。没有字幕的视频，用 OCR 抓烧录字幕替代。
- **不帮你总结。** 只负责把原料备好，动脑子的活儿交给你选的那个 AI。
- **不下载视频，不解析你没打开的链接。** 只处理你此刻正看着的这一页。
- **不上传任何东西。** 没有服务器，没有账号，不调用任何云端模型。

## 支持的平台

九个平台有专门的提取规则；**其它任何网页也能用**，会退回通用模式抓正文主体。

| 平台 | 正文 | 作者 | 评论 | 字幕 |
|---|---|---|---|---|
| 小红书 | ✅ | — | ✅ | — |
| YouTube | ✅ | ✅ | — | ✅ **整篇** |
| X / Twitter | ✅ | ✅ | ✅ | 仅当前可见 |
| Instagram | ✅ | ✅ | ✅ | 仅当前可见 |
| TikTok | ✅ | ✅ | ✅ | 仅当前可见 |
| Reddit | ✅ | ✅ | ✅ | — |
| Threads | ✅ | ✅ | ✅ | 仅当前可见 |
| LinkedIn | ✅ | ✅ | ✅ | 仅当前可见 |
| Facebook | ✅ | ✅ | ✅ | 仅当前可见 |
| 其它网页 | 通用 | 看情况 | — | 仅当前可见 |

"仅当前可见"= 只能拿到此刻显示在屏幕上的那一两句，不是整篇。
想要整段，用「画面」一边播一边扫。评论默认关闭，需在设置里打开。

## 安装

还没有上架 Chrome 应用商店，用开发者模式手动装，只做一次。

```
git clone https://github.com/LeeSoonDer/social-media-summarizer.git
```

1. 地址栏输入 `chrome://extensions`，回车
2. 打开右上角的**开发者模式**
3. 点**加载已解压的扩展程序**，选中刚 clone 下来的文件夹
4. 点地址栏右边的拼图图标，把它**固定**出来

不需要 `npm install`，没有构建步骤——`node_modules/` 只是为了从 npm 取 Tesseract 的文件，
运行时用的是已经提交进仓库的 `vendor/tesseract/`。

> **仓库较大（约 100MB）**，因为 OCR 语言包直接打包在 `vendor/` 里，运行时不联网下载。

## 三步上手

1. 打开一条小红书笔记或 YouTube 视频，**点扩展图标**（或 <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd>），
   右侧开出工作台，标题和正文自动采好
2. 内容在图里或视频里？切到**画面**分区点**扫本屏**（或 <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>）
3. 点底部**复制给 AI**，粘进任意 AI 对话框

工作台**不随翻页关闭**，可以一直开着刷，看到值得留的就采一条。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | 打开工作台 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 扫当前这一屏的画面文字 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | 跳到笔记输入框，马上记一句 |

## 隐私

- **不上传任何内容。** 没有服务器，没有账号，不调用云端 AI。
- **OCR 在本机跑。** 识别引擎和语言包打包在扩展里，运行时不联网。
- **数据只存在这台电脑的 Chrome 里。** 唯一的备份手段是设置页的「导出 JSON」。
- **唯一的联网行为**是取 YouTube 的字幕轨道，那是向 YouTube 自己要的。

安装时 Chrome 会提示它"可以读取你访问的所有网站的数据"——这是截屏 OCR 必需的权限，
Chrome 不提供更细的授权粒度。它只在你主动点按钮时才读当前这一页。

## 怎么做的

- **Manifest V3 + Side Panel API**，纯 vanilla JS，无框架、无构建链
- **Tesseract.js 本地 OCR**：截图先裁到内容区（视频 / 主图 / 正文容器）再放大送识别，
  识别结果按每行的置信度过闸——不裁不过闸的话，导航栏和侧栏推荐会把结果淹掉
- **集合与笔记分表存储**，清空集合不会动笔记
- **笔记按归一化后的内容 id 绑定页面**：剥掉 `xsec_token`、`igshid`、`utm_*` 这类易变参数，
  同一条内容从不同途径打开认的是同一页

```
manifest.json      background.js      sidepanel.{html,js,css}
content.js         平台提取路由
lib/ocr.js         截图 · 裁剪 · 识别 · 多屏合并
lib/store.js       集合 / 笔记 / 文件夹 / 设置
lib/format.js      给 AI 的两档稿
lib/notes.js       笔记 UI
vendor/tesseract/  本地 OCR 引擎与语言包
ai/                项目记忆（决策记录、当前状态、路线图）
```

## 已知限制

- **社交网站改版，提取规则就会失效。** 工作台的「提取说明」会写明正文来自平台选择器、
  og/meta 摘要还是可见文字兜底——看到后两者，说明那个站的规则该修了。
- **笔记还不能挪进文件夹。** 文件夹能建能改名能导出能删，笔记只会待在收集箱里。
- **笔记多了会卡。** 没有折叠、搜索和分页。
- **删除没有撤销。**
- **画面只扫当前一屏**，不会自动翻轮播的下一张。
- **口播分区对大多数页面是空的**，只有提供字幕轨道的网站才有内容。
